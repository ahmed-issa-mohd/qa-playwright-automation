# Login Test Cases

| TC ID | Test Case | Expected Result |
|---|---|---|
| TC-001 | Login with valid username and valid password | User is successfully logged in and redirected to the Home/Inventory page. |
| TC-002 | Login with invalid username and invalid password | Login fails and an error message is displayed. |
| TC-003 | Login with valid credentials and press Enter | User is successfully logged in and redirected to the Home/Inventory page. |
| TC-004 | Login without entering username and password | Login fails and an error message is displayed. |
| TC-005 | Login with invalid username and valid password | Login fails and an error message is displayed. |
